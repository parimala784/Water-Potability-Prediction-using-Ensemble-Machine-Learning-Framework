1. ABSTRACT
--------------------------------------------------------------------------------

This project presents an end-to-end machine learning system for predicting water
potability based on nine physicochemical parameters. The system employs multiple
classification algorithms—including Random Forest, XGBoost, CatBoost, LightGBM,
SVM, Extra Trees, and MLP Neural Networks—combined with SMOTE oversampling and
synthetic data augmentation to address class imbalance. An ensemble and stacking
meta-learner are used to improve robustness. The models achieve approximately
64–67% accuracy on the Water Potability dataset, with the best model selected
automatically after training.

A modern web application built with React, TypeScript, and FastAPI provides an
interactive interface for making predictions, viewing dataset statistics, and
exploring visualizations. Features include a model switcher (defaulting to the
best-performing model), a dataset analytics dashboard, correlation heatmaps,
distribution charts, and a chatbot with 100+ water quality Q&A. The application
supports dark and light themes and is fully responsive.

Keywords: Water potability, machine learning, classification, ensemble methods,
SMOTE, React, FastAPI, data visualization.

3. MODELS
--------------------------------------------------------------------------------

| ID         | Model Name              | Description                                      |
|------------|-------------------------|--------------------------------------------------|
| logistic   | Logistic Regression      | Linear classifier with L2 regularization        |
| rf         | Random Forest            | Ensemble of decision trees                       |
| brf        | Balanced Random Forest   | RF with per-tree undersampling for imbalance     |
| svm        | SVM (RBF)                | Support vector machine with RBF kernel           |
| extratrees | Extra Trees              | Random forest variant with extra randomness      |
| mlp        | MLP Neural Network       | Multi-layer perceptron (ReLU/tanh)               |
| xgboost    | XGBoost                  | Gradient boosting (XGBoost)                      |
| catboost   | CatBoost                 | Gradient boosting (Yandex)                      |
| lightgbm   | LightGBM                 | Gradient boosting (Microsoft)                    |
| ensemble   | Ensemble (Voting)        | Soft voting over base classifiers               |
| stacking   | Stacking (Meta-Learner)  | Meta-learner on base model probabilities         |

Training: SMOTE + synthetic jitter; StandardScaler; RandomizedSearchCV with
accuracy scoring. Best model by accuracy (F1 tie-breaker) is saved as default.
